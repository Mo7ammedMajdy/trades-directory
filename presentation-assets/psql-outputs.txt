### 2. One table in full, with every constraint
                                      Table "public.branch"
    Column    |         Type          | Collation | Nullable |              Default               
--------------+-----------------------+-----------+----------+------------------------------------
 id           | integer               |           | not null | nextval('branch_id_seq'::regclass)
 shop_id      | integer               |           | not null | 
 address      | text                  |           | not null | 
 branch_name  | text                  |           |          | 
 phone_number | character varying(15) |           | not null | 
Indexes:
    "branch_pkey" PRIMARY KEY, btree (id)
Check constraints:
    "branch_phone_number_check" CHECK (phone_number::text ~ '^\+?[0-9]{7,15}$'::text)
Foreign-key constraints:
    "branch_shop_id_fkey" FOREIGN KEY (shop_id) REFERENCES shop(id) ON DELETE CASCADE
Referenced by:
    TABLE "employee" CONSTRAINT "employee_branch_id_fkey" FOREIGN KEY (branch_id) REFERENCES branch(id) ON DELETE CASCADE
